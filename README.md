# Flash Flood Observatory

Source for [flashfloodobservatory.com](https://flashfloodobservatory.com/), a public dashboard of river level, rainfall and historical observations.

The dashboard includes accessible chart readings, light and dark appearance, and optional spoken explanations. Environment Agency flood alerts and warnings are supplementary official information, not warnings generated by the observatory.

## Run locally

Use Node.js 22 and Python 3.12. From this repository:

```sh
npm ci --ignore-scripts
npm test
python3 -m http.server 8769 --bind 127.0.0.1 --directory public
```

Open http://127.0.0.1:8769. To generate narration for the preview, follow the [development guide](docs/development.md#optional-narration-preview).

## Contributing

Read [AGENTS.md](AGENTS.md) and the [development guide](docs/development.md). Run `npm test` after changes and `npm run audio:text` when changing narrated text. Preview relevant chart windows, hydrological years and narrow-screen layouts.

The [payload reference](docs/payload.md) describes the public data fields. Coordinate contract changes with the producer and update the consumer, fixtures, tests and documentation together.

## Publication and privacy

This is a public repository: documentation and configuration are public even when they are not served on the website. Keep credentials, private machine paths, raw private measurements and operational runbooks outside this repository.

The [GitHub Pages workflow](.github/workflows/deploy-pages.yml) publishes only `public/`. This deployment boundary does not make other repository files private.

The contact payload supports an optional `email_base64` item (see [payload contract](docs/payload.md)). The combined rainfall/flow chart uses independent zero-based display limits for positive-flow windows, placing the flow peak above the rainfall maximum; measurements, tooltip values and tables are unchanged. Zero-flow windows retain the fallback scale.

### Today at the Observatory

The optional `observatory_summary` payload provides three calendar-based narratives
in UK local time: today to the latest observation, yesterday, and the five complete
days before today. It sits between the introduction and river-level summary.
Headlines reflect maximum minus minimum depth within each day (the largest daily
range for the five-day tab), never a first-to-last trend or flood-warning status.
Paragraphs use the same cleaned source measurements as the charts, and comparisons
use the full-precision Observatory mean behind the heatmap. Missing rainfall is not
zero: partial totals and depth coverage are stated explicitly. Positive rainfall
recorded today uses the approved simpler wording “X mm of rain has been recorded
today”, while retaining the underlying coverage checks.

The renderer displays the supplied headline and paragraph, with keyboard-operable
tabs and one read-aloud control. Changing tabs stops playback. Audio builds include
every tab and expiry fallback. Current summaries expire within an hour, and all
relative-day summaries expire at UK midnight. The weather symbol is omitted unless
retrieval and reuse can be verified. Expandable chart-value tables are not shown.
